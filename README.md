# protograf-demo

This repository contains demos and examples to help you create graphic designs
with the **protograf** library.

Please see https://github.com/gamesbook/protograf for the code; and
https://protograf.readthedocs.io/en/latest/index.html for documentation.

## Disclaimer

Examples are created at different times. API or code changes implemented over
time may cause discrepancies in the scripts.

Examples may not be updated every time a **protograf** update is released, so
there is no guarantee they all will work as originally expected.

If you look at the scripts as what they are intended to be, examples, then
they will give you a good start.
